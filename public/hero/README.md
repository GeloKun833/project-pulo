# Hero carousel images

Place your hero background images here. The home page carousel will cycle through them.

**Expected files:**
- `hero-1.jpg`
- `hero-2.jpg`
- `hero-3.jpg`

You can use more or fewer images by updating the `HERO_IMAGES` array in `src/App.tsx`.

Use landscape images (e.g. 1920×1080 or 1600×900) for best results. They will be cropped to cover the hero area.
